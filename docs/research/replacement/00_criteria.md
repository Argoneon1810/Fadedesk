# 요구사항 및 대안 평가 기준표 (`/grill-me` 인터뷰 확정본)

작성 시각: 2026-11-12  
근거: [INTENT.md](../../../INTENT.md) 1~2단계 인터뷰 결과

---

## 1. 한 줄 정의

**Chrome의 모든 창·백그라운드 탭에서 재생 중(또는 일시정지 대기 중)인 미디어들을 우측 상단 확장프로그램 팝업 하나에서 모아 보고, 탭 이동 없이 재생/일시정지·개별 볼륨(증폭 포함)·음소거/Solo·탭 이동·도메인 볼륨 기억을 수행하는 오픈소스 중앙 사운드 패널.**

---

## 2. 타협할 수 없는 조건 (Non-negotiables / 대안 즉시 탈락 기준)

기존 무료 대안을 평가할 때 아래 항목 중 하나라도 정면 위배되면 단독 완성 대안으로는 부적합 판정한다(단, 부분 충족 수준이 높은 오픈소스 후보는 비교 참고용으로 기록하고 사용자 인터뷰에 회부한다).

| 구분 | 필수 요건 | 즉시 탈락(Dealbreaker) 사유 |
|---|---|---|
| **비용·투명성** | 완전 무료 + **오픈소스** | 클로즈드소스, 외부 서버 통신/트래커, 광고, 유료(Pro/Freemium) 잠금·유도 포함 |
| **관리 범위** | Chrome 전체 창 + 모든 백그라운드 탭 통합 | 현재 활성 탭 하나만 제어하거나 단일 창에만 묶임 |
| **패널 형태** | 우측 상단 확장프로그램 툴바 팝업 (클릭 또는 단축키 호출) | 매번 별도 설정 탭을 열어야 하거나 팝업 중앙 패널이 없음 |
| **백그라운드 즉시 제어** | 현재 탭을 떠나지 않고 팝업에서 다른 백그라운드 탭 볼륨·재생 즉시 조작 | 볼륨 조절을 위해 해당 백그라운드 탭으로 한 번이라도 직접 이동·클릭해야 함 (`activeTab` 의존) |
| **`tabCapture` 부작용 배제** | 파란 녹화 아이콘 없음, 전체화면 유지, 오디오 지연/열화 없음 | `chrome.tabCapture` 사용으로 파란 탭 공유 아이콘 노출, 전체화면 해제/불가, 블루투스·오디오 딜레이 유발 |
| **핵심 제어 기능** | ① 탭별 볼륨 조절 + Mute 토글<br>② 재생 / 일시정지(Play/Pause)<br>③ 100% 초과 볼륨 증폭(Boost)<br>④ 특정 탭만 듣기(Solo) 또는 타 탭 일괄 제어<br>⑤ 클릭 한 번으로 해당 탭/창 포커스 이동 | 볼륨만 있고 재생 제어가 없거나, 재생 제어만 있고 볼륨/증폭이 없음 |
| **오디오 소스 감지** | `MediaSession` 미지원 소스(일반 `<video>`/`<audio>`, 라이브, SNS 영상, WebAudio 등)까지 포착 | Chrome 기본 미디어 허브처럼 `MediaSession` 등록 사이트만 뜨고 나머지 소리 나는 탭이 누락됨 |
| **탭 목록 유지 기준** | 현재 소리 나는 탭 + **일시정지된 미디어 탭** 함께 표시(시각적 구분) | 일시정지하는 순간 목록에서 사라져 팝업에서 다시 재생(Resume)할 수 없음 |
| **도메인 볼륨 기억** | 도메인별 초기 볼륨 기억 + **열린 뒤에는 탭마다 독립 볼륨 조작** (도메인 기본값 저장은 별도 핀/저장/옵션으로 분리) | 도메인 기억이 아예 없거나, 같은 사이트 탭 2개를 열었을 때 한쪽 조작이 이미 열린 다른 탭 볼륨까지 강제로 바꿔 버림 |

## 3. 타협 가능한 조건 — 강하게 선호 (Strong Preferences)

> VoiceMeeter는 UX 아이디어 참고용이며 엄격한 벤치마킹 대상이 아니다. 무료 대안이 아래 UI 형태를 그대로 따르지 않더라도 본질 기능을 충족하면 후보로 올릴 수 있으며, 직접 제작하게 될 경우 우선 반영할 항목이다.

1. **dB(데시벨) 로그 스케일 페이더 + `Mute(M)` / `Solo(S)` 버튼**
   - 퍼센트(%) 선형 슬라이더보다 청감상 조절 해상도가 균일한 dB 단위 페이더(예: `-60 dB ~ +12 dB`, 더블클릭 시 `0 dB` 원복).
2. **실시간 오디오 레벨 미터 (VU 미터)**
   - 여러 탭 중 지금 실제로 어느 탭에서 얼마나 큰 소리가 출력되는지 즉시 식별.
3. **마스터 페이더 (Master Strip)**
   - 열려 있는 미디어 탭 전체의 출력 레벨을 한 번에 비례 조절하거나 일괄 음소거.

## 4. 타협 가능한 조건 — 백로그 / Advanced 모드 후보 (Optional)

- 재생 위치 탐색바(Seek) 및 앞뒤 건너뛰기 · 이전/다음 트랙
- 자동 덕킹(Auto-Ducking: 기준 탭 음성 출력 시 타 탭 볼륨 자동 감쇠)
- `+dB` 증폭 시 피크 찢어짐(클리핑) 방지용 리미터(Limiter) / 컴프레서
- 좌우 밸런스(Pan) · 모노 전환 · EQ 필터

## 5. 확정된 추가 설계 원칙 (대안 기각 인터뷰 이후 반영)

1. **UI 레이아웃 방향 — 비대한 리스트 카드 배제, 슬림 오디오 채널 스트립 채택**:
   - 위아래로 쌓이는 뚱뚱한(bulky) 가로 리스트 아이템 형태를 지양하고, 각 탭이 **컴팩트한 세로 오디오 채널 스트립(Channel Strip)**으로 나란히 배열되는 콘솔 형태를 지향한다.
2. **차별화 기능 — Focus 모드 (`F`, 일반화된 Solo)**:
   - Solo(`S`)가 선택 채널만 남기고 나머지 채널을 완전 무음(`0` / `-∞ dB`)으로 만드는 것이라면, **Focus(`F`)는 선택 채널은 높은 볼륨을 유지하고 나머지 채널들은 완전히 끄지 않은 채 낮은 볼륨(감쇠된 배경 볼륨)으로 유지해 모든 소리를 들으면서도 볼륨 배분을 Focus 채널 중심으로 재편하는 모드**다.
3. **보안 제한(CORS/DRM) 예외 영상 처리 방침 확정**:
   - `chrome.tabCapture` 권한은 일절 사용하지 않는다.
   - 넷플릭스 등 DRM 영상이나 CORS 미허용 외부 직결 `<video>`에서만 `+dB` 증폭을 막고 안전하게 `0 dB`(원본 100%) 상한으로 자동 폴백한 뒤 UI에 작게 표시한다.
