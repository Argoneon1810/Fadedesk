# Fadedesk 한국어 문구 3차 검토 요청: 화면 투어 카드

## 요청

화면 투어는 8단계입니다. 단계마다 화면의 한두 곳을 밝게 비추고, 옆에 작은 설명 카드를 띄웁니다.
지금 카드 설명은 단계마다 긴 문장 하나에 여러 동작을 쉼표로 이어 붙여서 잘 읽히지 않습니다.

카드를 **제목 한 줄 + 짧은 줄 2~3개(글머리표)**로 바꾸려고 합니다. 줄마다 동작 하나만 담습니다. 이 모양에 맞춰 8개 카드의 제목과 줄을 새로 써 주세요.

## 카드 크기와 규칙

- **줄**: 띄어쓰기를 포함해 **24자 이내**로 써 주세요. 넘으면 두 줄로 접혀 읽기 어려워집니다.
- **줄 수**: 카드마다 **2~3줄**입니다. 8단계만 4줄까지 됩니다.
- **제목**: 18자 안팎입니다(두 줄로 접혀도 되지만 짧을수록 좋습니다). 비추는 곳의 이름이 드러나야 합니다.
- **줄의 꼴**: 사용자가 "무엇을 하면 → 무엇이 되는지"를 바로 알게 써 주세요. 어미는 8개 카드 전체에서 한 가지로 맞춰 주세요(예: "~합니다" 또는 "~해요" 또는 명사형).
- 기호(● ? ↗ 📌 ⠿ ▾ ▸ 🔗 α)와 버튼 이름은 화면과 똑같이 써 주세요. 화면 이름은 아래 "화면에 실제로 적힌 이름"에 있습니다.
- 아래 "할 수 있는 것"에 없는 기능을 새로 만들지 말아 주세요. 다 담지 않아도 됩니다. 중요한 것만 골라 주세요.
- 1·2차에서 정한 용어를 씁니다.
  - 모든 채널 / 이 채널만
  - 콘솔 안은 채널, 브라우저 자체는 탭
  - 음량, 사이트 고정 핀, 대기 구역
  - Solo = 이 채널만 듣기, Focus = 다른 채널 줄이기

## 돌려주실 형식

아래 꼴 그대로 8개 모두 주세요(키를 그대로 써 주세요).

```
help.tourSteps[0].title: (제목)
help.tourSteps[0].desc:
- (줄)
- (줄)
```

---

## 단계별 사실

### 1단계 — `help.tourSteps[0]`
- 비추는 곳: 왼쪽 위 색상 점(●), 도움말(?) 버튼, 창 분리(↗) 버튼
- 할 수 있는 것: ●를 눌러 컬러 테마 4종과 다크·라이트·시스템 화면 모드를 바꿈. ?를 눌러 사용법과 안전 안내를 언제든 다시 봄. ↗를 눌러 콘솔을 별도 창으로 띄워 둠(크기 조절 가능).
- 지금 제목: 상단 테마 · 도움말(?) · 독립 창 분리(↗)
- 지금 설명: 좌측 색상 점(●)에서 테마·모드를 바꾸고, 창 분리(↗) 버튼으로 콘솔을 별도 창으로 떼어내 항상 띄워 둘 수 있습니다.

### 2단계 — `help.tourSteps[1]`
- 비추는 곳: 채널 맨 위 머리(사이트 아이콘 · 사이트 이름 · ↗)
- 할 수 있는 것: 머리를 누르거나, 채널을 고른 뒤 Enter를 누르면 그 소리가 나는 브라우저 탭과 창으로 바로 이동함(창이 여러 개여도 됨).
- 지금 제목: 채널 헤더 클릭 → 해당 탭 바로 이동(↗)
- 지금 설명: 파비콘·사이트명·↗ 영역을 클릭(또는 Enter)하면 여러 창의 수많은 탭 중에서 소리가 나는 해당 탭으로 즉시 이동합니다.

### 3단계 — `help.tourSteps[2]`
- 비추는 곳: 채널 가운데 페이더(세로 볼륨 막대와 사각 노브), 그 아래 숫자 표시창
- 할 수 있는 것: 사각 노브를 위아래로 끌어 -60dB ~ +12dB 조절(0 위로 올리면 원래보다 크게). 막대 위에서 마우스 휠로 조절(Shift+휠은 미세 조절). 더블클릭하면 0.0dB. 아래 숫자창을 눌러 -8.5처럼 직접 입력.
- 지금 제목: 페이더 노브 드래그 & dB 직접 입력
- 지금 설명: 사각 노브를 끌어 -60dB~+12dB까지 조절하고, 아래 숫자창을 클릭해 원하는 데시벨을 직접 타이핑할 수 있습니다.

### 4단계 — `help.tourSteps[3]`
- 비추는 곳: 채널 아래쪽 재생 버튼과 압정(📌) 버튼, 채널 맨 위 왼쪽 6점 손잡이(⠿)
- 할 수 있는 것: 재생 버튼으로 그 탭을 재생/일시정지. 📌(사이트 고정 핀)를 켜면 지금 볼륨을 이 사이트의 기본 볼륨으로 기억해, 같은 사이트를 새 탭으로 열 때 그 볼륨으로 시작. ⠿를 끌어 채널 순서를 바꿈. 구분선 오른쪽 대기 구역에 놓으면 일시정지, 왼쪽으로 옮기면 다시 재생.
- 지금 제목: 재생 전환 · 사이트 고정 핀(📌) · 드래그 정렬(⠿)
- 지금 설명: 재생 옆 압정(📌)을 켜면 사이트 기본 볼륨으로 기억되며, 맨 위 6점 핸들(⠿)을 우측 대기 구역에 놓으면 즉시 일시정지됩니다.

### 5단계 — `help.tourSteps[4]`
- 비추는 곳: 채널 맨 아래 M·S·F 버튼, 위쪽 바의 "Focus α" 상자와 "S·F 해제" 버튼
- 할 수 있는 것: M = 음소거. S(Solo) = 이 채널만 듣기. F(Focus) = 이 채널은 그대로 두고 다른 채널 줄이기. Shift+클릭으로 여러 채널을 함께 고름. Focus α는 다른 채널을 얼마나 줄일지 정함(노브를 끌거나, 숫자를 눌러 dB 입력). "S·F 해제"는 켜진 Solo·Focus를 한 번에 끔.
- 지금 제목: 집중 청취(M · S · F)와 상단 Focus α
- 지금 설명: F(Focus)를 켜면 이 탭만 또렷하게 두고 다른 탭들은 상단 Focus α 비율만큼 줄입니다. 우측 데시벨 수치도 직접 입력할 수 있습니다.

### 6단계 — `help.tourSteps[5]`
- 비추는 곳: 위쪽 바 오른쪽의 "균일 N" 버튼과 그 옆 ▾
- 할 수 있는 것: "균일 N"을 누르면 모든 채널 노멀라이저(탭마다 다른 음량을 자동으로 맞춤)를 켜고 끔. ▾를 누르면 프리셋(클래식 · 음악 · 표준 · 야간)이나 내 프리셋을 고름. 고급 FX에서 '이 채널만'으로 따로 정한 채널은 여기 설정을 따르지 않음.
- 지금 제목: 모든 채널 노멀라이저(균일 N ▾)
- 지금 설명: 본체로 모든 채널 노멀라이저를 켜고 끄며, 우측 ▾에서 클래식 · 음악 · 표준 · 야간 프리셋이나 내 프리셋을 고릅니다. '이 채널만'으로 따로 둔 채널은 건드리지 않습니다.

### 7단계 — `help.tourSteps[6]`
- 비추는 곳: 오른쪽 끝 마스터 버스(전체 볼륨 페이더, "전체 FX", "전체 정지", "전체 음소거")
- 할 수 있는 것: 페이더로 전체 볼륨 조절. "전체 정지"로 모든 탭을 한 번에 일시정지(다시 누르면 재생). "전체 음소거"로 한 번에 음소거. "전체 FX"를 누르면 고급 FX 랙이 "모든 채널" 설정 화면으로 열림.
- 지금 제목: 마스터 버스 · 전체 FX
- 지금 설명: 우측 마스터 버스에서 전체 볼륨과 전체 정지·음소거를 조절합니다. '전체 FX'를 누르면 모든 채널의 효과를 한 번에 설정할 수 있도록 고급 FX 랙이 열립니다.

### 8단계 — `help.tourSteps[7]` (4줄까지)
- 비추는 곳: 오른쪽에 열린 고급 FX 랙 전체, 모든 채널 맨 위의 N·G·C·P 배지 줄
- 할 수 있는 것: 랙 맨 위 [모든 채널 | 이 채널] 탭으로 설정할 대상을 고름. 카드가 "🔗 모든 채널 따름"이면 잠겨 있고, "이 채널만 따로"를 눌러야 이 채널만 바꿀 수 있음. 카드의 "세부 ▸"에서 값을 자세히 바꾸고, "내 프리셋으로 저장"해 다른 채널에서도 씀. 채널 위 N·G·C·P 배지는 그 채널에 지금 켜진 효과(노멀라이저·노이즈 게이트·컴프레서·패닝).
- 지금 제목: 고급 FX 랙: 모든 채널 · 이 채널
- 지금 설명: 랙 상단 탭에서 설정할 대상을 선택합니다. '🔗 모든 채널 따름' 상태인 카드는 잠겨 있으므로 '이 채널만 따로'를 눌러야 개별 조절이 가능합니다. '세부 ▸'에서 바꾼 값은 내 프리셋으로 저장할 수 있으며, 채널 상단의 N·G·C·P 배지는 현재 켜져 있는 효과를 나타냅니다.

## 화면에 실제로 적힌 이름

균일 N, ▾, 고급 FX ▸, S·F 해제, Focus α, 전체 FX, 전체 정지, 전체 음소거, 모든 채널, 이 채널, 🔗 모든 채널 따름, 이 채널만 따로, 세부 ▸, 내 프리셋으로 저장, M, S, F
