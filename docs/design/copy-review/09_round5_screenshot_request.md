# Fadedesk 한국어 문구 5차 검토 요청: 스토어 스크린숏 위 제목

## 요청

Chrome 웹 스토어 스크린숏(1280×800)은 화면 위쪽에 짧은 머리표, 큰 제목, 설명 한 줄을 얹고 그 아래에 실제 콘솔 화면을 보여 줍니다.
한국어 스크린숏 2장(3번, 4번)의 이 세 줄이 1.0.0 때 문구라 낡았습니다. 아래 사실에 맞춰 새로 써 주세요.

## 자리와 길이

- **머리표**(kicker): 작은 글씨 한 줄입니다. 40자 이내로 써 주세요. 지금은 "FADEDESK · …" 꼴입니다.
- **제목**(headline): 큰 글씨(26px)입니다. 한 줄에 들어가게 **35자 이내**로 써 주세요.
- **설명**(subtitle): 보통 글씨(14px)입니다. 한 줄에 들어가게 **70자 이내**로 써 주세요.
- 앱 안 문구에서 정한 용어를 씁니다.
  - 화면 투어(실화면 대신), 사이트 고정 핀, 모든 채널 / 이 채널만
  - Focus = 다른 채널 줄이기("감쇠" 대신), 차단 기준
- 아래 "그림에 보이는 것"에 없는 기능을 쓰지 마세요.

## 돌려주실 형식

```
3.kicker: …
3.headline: …
3.subtitle: …
4.kicker: …
4.headline: …
4.subtitle: …
```

## 3번 스크린숏 — 화면 투어 8단계

- **그림에 보이는 것**
  - 콘솔 위에 화면 투어 8단계 카드가 떠 있습니다. 카드 제목은 "고급 FX 랙: 모든 채널 · 이 채널"입니다.
  - 오른쪽에 열린 고급 FX 랙과, 채널마다 맨 위의 N·G·C·P 배지 줄이 밝게 비춰져 있습니다.
  - 카드 줄은 이렇습니다.
    - 상단 탭에서 모든 채널 · 이 채널을 고릅니다
    - 이 채널만 따로를 눌러야 개별 조절이 됩니다
    - 세부 ▸에서 바꾼 값을 내 프리셋으로 저장합니다
    - 채널 위 N·G·C·P는 현재 켜진 효과입니다
- **알릴 것**
  - 투어는 8단계이고, 실제 콘솔 화면을 비추며 짧은 카드로 안내합니다.
  - 열린 미디어 탭이 없어도 예시 채널 2개로 체험할 수 있습니다.
  - 한국어와 영어를 지원합니다.
- **지금 문구**
  - 머리표: FADEDESK · 한·영 동시 지원 & 실화면 스포트라이트 투어
  - 제목: 실제 콘솔 위에서 연관 조작부를 한눈에 비추는 7단계 인터랙티브 투어
  - 설명: 하단 집중 청취(M·S·F)와 상단 Focus α 감쇠 슬라이더·직접 입력창을 다중 스포트라이트 홀로 안내

## 4번 스크린숏 — 도움말 창의 안전·유의사항

- **그림에 보이는 것**
  - 콘솔 위에 도움말 창(? 버튼)이 열려 있고, "콘솔 사용법" 탭의 마지막 단계 "안전 및 유의사항"이 보입니다.
  - 내용은 청력·스피커 보호, 통화·경보 주의, 시험·보안 페이지·웹 DAW 호환, 계측·화면 공유·무보증 안내입니다.
  - 도움말 창에는 밑줄 친 기능 이름에 마우스를 올리면 위치를 보여 주는 안내 그림도 있습니다.
- **알릴 것**
  - 설치 뒤 언제든 ? 버튼으로 사용법과 안전 안내를 다시 볼 수 있습니다.
- **지금 문구**
  - 머리표: IN-APP CONSOLE GUIDE & SAFETY NOTICES
  - 제목: 설치 후 언제든 열람 가능한 부품 도면 가이드와 안전·유의사항 고지
  - 설명: 청력·스피커 보호, 통화·경보 감쇠 주의, 시험·보안 페이지 호환, BS.1770 계측 기준을 인앱 ? 버튼에 상시 수록
