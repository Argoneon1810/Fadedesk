- 별도 창은 크기만 저장하는데 "크기와 위치"라고 적혀 있습니다.
- 세션 저장 항목에 탭 주소(URL)와 미디어 제목이 빠져 있습니다.

## 실제로 저장하는 것 (코드에서 확인)

### 영구 저장소 (`chrome.storage.local`) — 확장을 지울 때까지 남음, 기기 밖으로 안 나감

1. 마스터 볼륨, 마스터 음소거
2. Focus α(다른 채널을 줄이는 폭)
3. 컬러 테마, 화면 모드(다크·라이트·시스템)
4. 별도 콘솔 창의 크기(가로·세로). 위치는 저장하지 않음
5. 고급 FX 랙을 열어 두었는지
6. 노멀라이저 그래프 보기 방식(스펙트럼 / 막대)
7. 모든 채널 효과 설정: 노멀라이저(켜짐 여부, 프리셋, 목표 음량, 유효 구간 등 값), 노이즈 게이트, 컴프레서, 전체 밸런스
8. 내 프리셋: 사용자가 직접 입력한 이름과 노멀라이저 값(최대 20개)
9. 화면 투어(온보딩)를 마쳤는지
10. 사이트 고정 핀: 사용자가 핀을 켰을 때만, 그 사이트 이름(예: `example.com`)과 기본 볼륨

### 세션 저장소 (`chrome.storage.session`) — 브라우저를 닫거나 탭을 닫으면 사라짐, 디스크에 영구 기록 안 됨, 기기 밖으로 안 나감

- 왜: 백그라운드 서비스 워커가 절전 상태에서 깨어날 때 콘솔의 채널 목록을 끊김 없이 되살리기 위해
- 무엇을: 소리가 나거나 미디어가 있는 탭마다
  1. 탭 주소(URL), 탭 제목, 재생 중인 미디어 제목, 도메인, 파비콘 주소
  2. 재생 상태
  3. 채널 순서
  4. 그 탭에 정한 볼륨, 음소거, Solo, Focus, 이 채널만 따로 정한 효과 설정

## 지금 글 (한국어)

```
2. **기기에 영구 저장하는 설정 (`chrome.storage.local`).** 사용자가 직접 고른 콘솔 설정만 브라우저 내부 저장소에 보관합니다. 저장 항목은 마스터 볼륨·음소거·전역 음량 평준화 여부, 테마 종류, 독립 콘솔 창 크기와 위치, 열려 있는 탭에 설정한 볼륨(dB)·음소거·Solo·Focus·스테레오 팬·노이즈 게이트·컴프레서·노멀라이저 값, 온보딩 투어 완료 여부, 그리고 **사용자가 직접 '도메인 볼륨 고정(핀)' 단추를 눌렀을 때 기록되는 해당 사이트의 도메인 이름(예: `example.com`)과 기본 볼륨 수치**입니다. 이 값은 기기 밖으로 나가지 않으며 확장을 삭제하면 함께 지워집니다.
3. **브라우저 실행 중에만 유지되는 임시 탭 상태 (`chrome.storage.session`).** 백그라운드 서비스 워커가 절전 상태에서 깨어날 때 콘솔 채널 목록을 끊김 없이 복원하기 위해, 현재 소리가 나거나 미디어가 감지된 탭의 제목·도메인·파비콘 주소·재생 상태를 브라우저 메모리의 세션 저장소에 임시로 보관합니다. 이 정보는 디스크에 영구 기록되지 않고 기기 밖으로 전송되지 않으며, 탭이나 브라우저를 닫으면 즉시 사라집니다.
```

항목 6의 `tabs` 줄:

```
   - `tabs`: 여러 창과 백그라운드 탭 중 미디어가 있는 탭을 식별해 콘솔 스트립에 제목·도메인·아이콘을 표시하고 도메인별 고정 볼륨을 적용하기 위해 사용합니다.
```
