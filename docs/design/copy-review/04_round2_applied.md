# 2차 Gemini 문구 검토 반영 기록 (2026-11-18, 1.2.3에 합침)

- 요청: `03_round2_request.md`. 사용자가 웹 Gemini에 넣어 받은 표의 7개를 그대로 반영했다.
- Gemini가 그대로 두라고 한 것: `help.easySteps[2].title`, `help.tourSteps[3].title`, `help.terms.tabJump.subtitle`, `help.terms.normSplit.subtitle`(기계적으로 맞춘 문구 확인됨), `help.easySteps[0].bullets[2]`("전역 단축키"는 표준 용어).
- 1.2.3을 Chrome에 불러오기 전이라 번호를 올리지 않고 1.2.3에 합쳤다.

| 키 | 1차 반영 뒤 | 2차 반영 |
|---|---|---|
| `ui.fxCorsSub` | 사이트 보안(CORS·DRM) 때문에 고급 FX가 작동하지 않습니다 | 사이트 보안으로 고급 FX 제한됨 |
| `fx.globalSub(n)` | 여기서 바꾸면 채널 {n}개에 모두 적용됩니다 | 채널 {n}개에 모두 적용됩니다 |
| `ui.toastZoneMoved(t, p)` (일시정지 쪽) | {t}: 일시정지 구역으로 이동 · 바로 정지 | {t}: 대기 구역으로 이동 · 바로 일시정지 |
| `help.advSteps[3].title` | 다이내믹 컴프레서 & 교차 출처 보안 제한(0dB) | 다이내믹 컴프레서 & 사이트 보안 제한(0dB) |
| `help.advSteps[3].bullets[1]` | 보안 제한(0dB): 교차 출처(CORS)·DRM 보호 미디어는 저작권 보호 정책을 존중해 기본 볼륨 제어(0dB 이하 감쇠)로 자동 전환되며 [페이더] 상단에 빗금이 표시되고 미터는 설정 볼륨 기준으로 표시됩니다. | 보안 제한(0dB): 사이트 보안(CORS·DRM)이 적용된 미디어는 저작권 보호를 위해 기본 볼륨 조절(0dB 이하로만 조절)로 자동 전환되며, [페이더] 상단에 빗금이 표시되고 미터는 설정 볼륨 기준으로 움직입니다. |
| `help.easySteps[4].bullets[1]` | 통화·경보 주의: 전체 음소거, Solo·Focus 감쇠, 노이즈 게이트는 다른 탭의 화상회의·호출·일정 알림·비상 경보음까지 함께 줄이거나 차단합니다. | 통화·경보 주의: 전체 음소거, Solo·Focus, 노이즈 게이트를 켜면 다른 탭의 화상회의·호출·일정 알림·비상 경보음까지 함께 줄어들거나 차단됩니다. |
| `help.terms.switchBank.description` | 채널 맨 아래 M · S · F 3버튼 묶음입니다. M(음소거), S(단독 청취), F(선택 탭 외 배경 탭 감쇠 · Shift+클릭 다중 선택)로 여러 탭 간의 청취 집중도를 빠르게 전환합니다. | 채널 맨 아래 M · S · F 3버튼 묶음입니다. M(음소거), S(이 채널만 듣기), F(다른 채널 줄이기 · Shift+클릭: 여러 개 선택)로 채널별 청취 집중도를 빠르게 전환합니다. |
