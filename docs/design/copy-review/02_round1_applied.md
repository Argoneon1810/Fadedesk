# 1차 Gemini 문구 검토 반영 기록 (2026-11-18, 1.2.3)

- 요청: `01_ko_review_request.md` (문구 331개)를 사용자가 웹 Gemini에 넣어 받은 검토표.
- 반영: Gemini가 고친 항목 99개를 키별로 그대로 넣었다(아래 표). 고치지 않은 항목은 원문 유지.

- 검토 밖에서 기계적으로 맞춘 것(Gemini 용어 통일표를 따름, 2차 검토 대상):

  - `popup.html`의 기본 툴팁·aria(실행 때 사전 값으로 덮어써짐)를 사전과 같게
- Gemini 용어 통일표(요지): 전역→모든 채널, 개별→이 채널만, 콘솔 안은 채널·브라우저는 탭, 음압→음량, 대표 구간→유효 구간, 0dB 회귀 텐션→원음 복귀 속도, 바닥·임계값→차단 기준, 걸리다·고치다·고르다→적용·설정·선택, 도메인→사이트.
