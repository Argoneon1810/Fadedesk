# Fadedesk 한국어 문구 4차 검토 요청: README와 스토어 상세 설명

## 요청

GitHub README(한국어)와 Chrome 웹 스토어 상세 설명(한국어) 가운데 **기능이 바뀌어 틀리게 된 단락만** 새로 써 주세요.
이 글들은 1.0.0 때 쓴 것이고, 그 뒤 1.1.0~1.2.3에서 기능과 화면 용어가 바뀌었습니다. 바뀐 사실은 아래 "바뀐 사실"에 정리했습니다.

판 번호, 링크, 시험 개수 같은 숫자는 개발 쪽에서 고치니 신경 쓰지 않으셔도 됩니다.

## 바뀐 사실 (1.1.0 ~ 1.2.3)

1. **노멀라이저 프리셋이 4종입니다**: 클래식 · 음악 · 표준 · 야간. 화면 배지에 보이는 값은 이렇습니다.
   - 클래식(원음 · 광대역): -16 LUFS, 15s. 아주 여린 소리나 폭발적인 연주에서는 보정을 멈추고 원래 볼륨으로 돌아갑니다. 최대 +4dB.
   - 음악(강약 보존 · 기본): -16 LUFS, 9s. 한 곡 안의 강약은 살리고 곡 사이 음량 차이만 맞춥니다. 최대 +6dB.
   - 표준(영상 · 방송): -16 LUFS, 3s. 유튜브·스트리밍·강의 탭을 오갈 때 목소리와 배경음 볼륨을 일정하게 맞춥니다. 최대 +7.5dB.
   - 야간(강한 균일): -18 LUFS, 0.4s. 갑작스러운 큰 소리는 빠르게 누르고 작은 대사는 또렷하게 둡니다. 최대 +9dB.
   - 새로 설치하면 균일 N은 켜져 있고(음악 프리셋), 1.0.0에서 넘어오면 쓰던 설정이 그대로 옮겨집니다.
2. **유효 구간**(1.1.0): 노멀라이저는 들어오는 소리 가운데 유효 구간(예: -32 ~ -10 LUFS) 안의 소리만 보고 볼륨을 맞춥니다. 구간 밖의 아주 작거나 큰 소리에서는 보정을 멈추고, 원음 복귀 속도에 따라 원래 볼륨(0.0dB)으로 천천히 돌아갑니다. 곡 중간의 조용한 구간에서 볼륨이 치솟지 않게 막는 장치(-10 LU 상대 게이트)는 그대로 있습니다. 세부 창에서 유효 구간을 실시간 스펙트럼 그래프(↕)나 막대(↔)로 보고 끌어 바꿀 수 있습니다.
3. **고급 FX가 "모든 채널"과 "이 채널"로 나뉘었습니다**(1.2.0).
   - 랙 맨 위 [모든 채널 | 이 채널] 탭, 또는 마스터 버스의 "전체 FX" 버튼으로 설정할 대상을 고릅니다. 지금 설정하는 대상(채널 또는 마스터 버스)은 바탕이 밝게 떠올라 보입니다.
   - 노멀라이저 · 노이즈 게이트 · 컴프레서는 카드마다 "🔗 모든 채널 따름"(잠김)이거나 "이 채널만"입니다. "이 채널만 따로"를 눌러야 그 채널 값만 바꿀 수 있고, "모든 채널 따르기"로 되돌립니다.
   - 패닝은 이 채널 값에 "전체 밸런스"(모든 채널 공통)가 더해집니다. 채널끼리의 좌우 간격은 유지한 채 전체 중심만 옮길 수 있습니다.
   - 랙에는 요약 카드 4개만 있고, "세부 ▸"를 누르면 옆에 세부 창이 열려 프리셋·유효 구간·원음 복귀 속도·목표 음량을 조절합니다.
   - 바꾼 노멀라이저 값은 "내 프리셋으로 저장"해 다른 채널에서도 고를 수 있습니다(최대 20개, 이름 바꾸기·삭제 가능). 상단 균일 N ▾ 목록에도 내 프리셋이 나옵니다.
   - 채널 맨 위에 N·G·C·P 배지가 있어 그 채널에 지금 켜진 효과(노멀라이저·노이즈 게이트·컴프레서·패닝)를 보여 줍니다.
   - 1.0.0의 "전역 따름 / 개별 ON / 개별 OFF" 세 단추는 없어졌습니다.
4. **Focus 전용 색**(1.2.0): Focus를 켠 채널은 테마마다 따로 정한 Focus 색으로 표시됩니다. 페이더는 높은데 실제로는 덜 들리거나 안 들리는 몫은 빗금으로 그리고, 빗금 색이 이유를 알려 줍니다(음소거 = 빨강, Solo 때문에 꺼짐 = Solo 색, Focus로 줄어듦 = Focus 색).
5. **화면 투어는 8단계**입니다(1.2.2). 단계마다 카드에 짧은 줄 2~4개로 안내하고, 8단계에서는 고급 FX 랙을 잠시 열어 보여 줍니다. 열린 미디어 탭이 없어도 예시 채널 2개로 체험할 수 있습니다.
6. **팝업을 열어 둘 때의 CPU 부담을 줄였습니다**(1.2.1). README에 꼭 넣을 필요는 없습니다.

```

![Fadedesk 채널별 고급 FX 사이드 랙](docs/store/screenshots/2-fx-rack.png)

상단 **`균일 N ▾`** 스플릿 버튼은 실시간 `ITU-R BS.1770-4` K-가중 라우드니스 계측과 `EBU Tech 3341` 시간 창을 바탕으로 탭 간 소리 크기 차이를 맞춰 줍니다. 곡 중간의 조용한 정적·잔향 구간에서 게인이 멋대로 치솟았다가 다음 박자에 귀를 때리지 않도록 **`-10 LU` 상대 게이트**가 자동 증폭을 잡아 둡니다.

| 프리셋 | 계측 창 · 목표 음압 | 어울리는 상황 |
| --- | --- | --- |
| **음악 (강약 보존)** | `9.0s` 완만 추종 · `-16 LUFS` | 잔잔한 도입부와 터지는 후렴의 곡 내 강약 연출을 해치지 않으면서 곡 간 음량만 맞출 때 |
| **표준 (영상·방송)** | `3.0s` 균형 추종 · `-16 LUFS` | 유튜브 영상, 라이브 방송, 강의, 여러 탭 동시 시청의 기본값 |
| **야간 (강한 균일)** | `0.45s` 민감 추종 · `-18 LUFS` | 밤 시간 작은 볼륨에서도 대사는 잘 들리고 갑작스러운 큰 효과음은 빠르게 누를 때 |

오른쪽 **`고급 FX ▸`** 를 펼치면 전역 `균일 N` 설정을 해치지 않고 선택한 탭마다 세부 음향을 다듬을 수 있습니다.

- **채널별 노멀라이저 덮어쓰기**: 전역 설정 따름(`Follow`) / 이 탭만 항상 켜기(`On`) / 이 탭만 끄기(`Off`) 및 목표 음압(`-20 ~ -12 LUFS`), 추종 속도 개별 지정
- **스테레오 패닝 (`Pan`)**: 여러 방송이나 강의를 동시에 들을 때 소리가 맺히는 좌우 위치(`L100 ~ C ~ R100`)를 갈라 귀에서 섞이지 않게 분리
- **노이즈 게이트 (`Gate`)**: 일정 크기(`-65 ~ -30 dB`) 아래로 내려간 마이크 바닥 잡음·화이트 노이즈를 부드럽게 차단
- **다이내믹 컴프레서 (`Comp`)**: `약(2:1)` · `중(4:1)` · `강(8:1)` 압축과 `-1.0 dBFS` 안전 피크 리미터로 갑작스러운 파열음과 클리핑 방지
```
