# Fadedesk 한국어 문구 2차 검토 요청

## 요청

지난번 검토(1차)에서 주신 수정안과 용어 통일표를 앱에 반영했습니다. 반영하고 보니 아래 세 가지가 남았습니다. 이것만 봐 주세요.

- **가.** 좁은 자리에서 잘리는 문구 2개
- **나.** 1차 용어 통일표를 따라 개발 쪽에서 기계적으로 바꾼 문구(자연스러운지 확인)
- **다.** 1차 표에 따로 행이 없어 아직 남은 "감쇠"와 "전역" 표현

1차에서 정한 용어를 그대로 씁니다.
- 범위: **모든 채널** / **이 채널만**. 콘솔 안의 대상은 **채널**이고, 브라우저 자체를 가리킬 때만 **탭**입니다.
- 음량: **음량**(음압 대신), **유효 구간**(대표 구간 대신), **원음 복귀 속도**(0dB 회귀 텐션 대신)
- 노이즈 게이트: **차단 기준**
- 도메인 핀: **사이트 고정 핀**
- Focus: 상단 바에서는 "Focus 볼륨 줄임(α)"으로 풀어 썼습니다.

지켜 주실 것은 1차와 같습니다.
- `{n}`, `{t}` 같은 자리 표시자와 기호·숫자·단축키는 그대로 둡니다.
- **가** 항목은 적힌 글자 수를 넘으면 안 됩니다.

## 가. 잘리는 문구 (글자 수 제한 엄수)

고급 FX 랙 맨 위 한 줄 설명입니다. 폭이 좁아(약 190px) 띄어쓰기를 포함해 **19자 이내**여야 끝까지 보입니다. 지금은 말줄임(…)으로 잘리고, 마우스를 올려야 전체가 보입니다.

- **ui.fxCorsSub**: 사이트 보안(CORS·DRM) 때문에 고급 FX가 작동하지 않습니다
  - 언제 보이나: 사이트 보안 때문에 이 채널에는 노멀라이저·게이트·컴프레서·패닝을 걸 수 없고, 볼륨은 0dB까지 줄이기만 됩니다.
- **fx.globalSub(n)**: 여기서 바꾸면 채널 {n}개에 모두 적용됩니다
  - 언제 보이나: "모든 채널" 탭을 열었을 때. `{n}`에는 지금 콘솔에 있는 채널 수(보통 한 자리)가 들어갑니다.

## 나. 개발 쪽에서 기계적으로 바꾼 문구 (자연스러운지 확인)

- **ui.toastZoneMoved(t, p)**: `{t}: 재생 구역으로 이동 · 바로 재생` / `{t}: 일시정지 구역으로 이동 · 바로 정지`
  - 채널을 끌어 재생/일시정지 구역으로 옮겼을 때 잠깐 뜨는 알림입니다. `{p}`는 두 문장 중 어느 것을 쓸지 고르는 값이라 화면에 나오지 않습니다.
  - 앞 문장은 1차 제안 그대로이고, 뒤 문장은 같은 꼴로 맞췄습니다.
- **help.easySteps[2].title**: 집중 청취(M·S·F) · 드래그 정렬 · 사이트 고정 핀
- **help.tourSteps[3].title**: 재생 전환 · 사이트 고정 핀(📌) · 드래그 정렬(⠿)
- **help.terms.tabJump.subtitle**: 파비콘 · 사이트 · ↗ 바로 이동 버튼
- **help.terms.normSplit.subtitle**: 상단 자동 음량 평준화 스플릿 버튼
- **help.advSteps[3].title**: 다이내믹 컴프레서 & 교차 출처 보안 제한(0dB)
  - 채널 아래 표시가 "보안 0dB 상한"에서 "보안 제한 (0dB)"로 바뀌어 이름을 맞췄습니다.

## 다. 아직 남은 "감쇠"·"전역" 표현

- **help.advSteps[3].bullets[1]**: 보안 제한(0dB): 교차 출처(CORS)·DRM 보호 미디어는 저작권 보호 정책을 존중해 기본 볼륨 제어(0dB 이하 감쇠)로 자동 전환되며 [페이더] 상단에 빗금이 표시되고 미터는 설정 볼륨 기준으로 표시됩니다.
- **help.easySteps[4].bullets[1]**: 통화·경보 주의: 전체 음소거, Solo·Focus 감쇠, 노이즈 게이트는 다른 탭의 화상회의·호출·일정 알림·비상 경보음까지 함께 줄이거나 차단합니다.
- **help.terms.switchBank.description**: 채널 맨 아래 M · S · F 3버튼 묶음입니다. M(음소거), S(단독 청취), F(선택 탭 외 배경 탭 감쇠 · Shift+클릭 다중 선택)로 여러 탭 간의 청취 집중도를 빠르게 전환합니다.
  - 1차에서 Solo 툴팁은 "이 채널만 듣기", Focus 툴팁은 "다른 채널 줄이기"로 바꿨습니다.
- **help.easySteps[0].bullets[2]**: 전역 단축키(Alt+Shift+M 콘솔 열기, Alt+Shift+0 전체 음소거, Alt+Shift+F Focus 순환 · macOS는 Ctrl+Shift)와 방향키·0·M/S/F/P 조작을 지원합니다.
  - 여기의 "전역"은 "팝업이 닫혀 있어도 브라우저 어디서나 동작하는" 단축키라는 뜻이라, FX 범위의 "전역"과 뜻이 다릅니다.
