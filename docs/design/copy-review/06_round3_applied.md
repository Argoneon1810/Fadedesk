# 3차 Gemini 문구 검토 반영 기록: 화면 투어 카드 (2026-11-18, 1.2.3에 합침)

- 요청: `05_round3_tour_request.md`. 사용자가 투어 카드가 "문장 하나로 억지로 이어 붙인 것 같아 잘 안 읽힌다"고 해서, 카드를 제목 + 짧은 줄(글머리표)로 바꾸고 문구를 Gemini에 새로 받았다.
- 반영: 받은 8개 카드의 제목과 줄을 그대로 넣었다(`help-copy.ts` `KO_HELP.tourSteps`, `desc`를 줄 목록으로). 어미는 Gemini가 "~합니다"로 통일했다.
- 글자 수: Gemini는 줄마다 24자 이하라고 했지만, 실제로는 25~27자인 줄이 8개 있다. 그래도 카드 폭(약 276px, 11px 글꼴)에서 한 줄에 들어가는 것을 화면과 감사(`TOUR_LINE_WRAPPED_*`)로 확인했다.
- 영어 투어 카드도 사용자 허락을 받아 같은 모양(제목 + 짧은 줄)으로 고쳤다. 영어는 Claude가 `05_round3_tour_request.md`의 단계별 사실만으로 썼고, 화면 용어는 영어 UI 이름(Level N, Clear S·F, All FX, Set separately, Details ▸ 등)을 따랐다. 가장 긴 줄 48자도 한 줄에 들어간다(감사 통과).

| 단계 | 제목 | 줄 |
|---|---|---|
| 1 | 테마(●) · 도움말(?) · 창 분리(↗) | ●를 눌러 테마와 화면 모드를 바꿉니다 / ?에서 사용법과 안전 안내를 다시 봅니다 / ↗를 눌러 콘솔을 별도 창으로 띄웁니다 |
| 2 | 채널 상단 클릭 → 탭 바로 이동(↗) | 사이트 이름이나 ↗를 눌러 탭으로 이동합니다 / 채널을 선택한 뒤 Enter를 눌러도 됩니다 |
| 3 | 페이더 노브 드래그 · 숫자 입력 | 노브를 끌어 -60~+12dB까지 조절합니다 / 더블클릭하면 0.0dB로 초기화됩니다 / 아래 숫자창을 눌러 dB를 직접 입력합니다 |
| 4 | 사이트 고정 핀(📌) · 드래그(⠿) | 📌를 켜면 이 사이트의 기본 볼륨이 됩니다 / ⠿를 좌우로 끌어 채널 순서를 바꿉니다 / ⠿를 대기 구역에 놓으면 바로 일시정지됩니다 |
| 5 | 집중 청취(M·S·F)와 Focus α | S는 이 채널만 듣고, F는 다른 채널을 줄입니다 / Focus α에서 다른 채널을 줄일 폭을 정합니다 / S·F 해제를 누르면 한 번에 모두 꺼집니다 |
| 6 | 모든 채널 노멀라이저(균일 N ▾) | 균일 N을 눌러 자동 음량 맞춤을 켜고 끕니다 / ▾에서 상황별 프리셋과 내 프리셋을 고릅니다 / '이 채널만' 설정된 채널은 그대로 유지됩니다 |
| 7 | 마스터 버스 · 전체 FX | 페이더로 콘솔 전체 볼륨을 조절합니다 / 전체 정지 · 전체 음소거로 한 번에 제어합니다 / 전체 FX를 눌러 모든 채널 효과를 설정합니다 |
| 8 | 고급 FX 랙: 모든 채널 · 이 채널 | 상단 탭에서 모든 채널 · 이 채널을 고릅니다 / 이 채널만 따로를 눌러야 개별 조절이 됩니다 / 세부 ▸에서 바꾼 값을 내 프리셋으로 저장합니다 / 채널 위 N·G·C·P는 현재 켜진 효과입니다 |
