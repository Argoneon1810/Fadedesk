# 3단계 설계 기록: 고급 FX의 적용 범위와 노멀라이저 두 축 분리 (`05_fx_scope_redesign.md`)

작성 시각: 2026-11-17
상태: **시안 문답 진행 중 (`1.2.0` 대상)**

---

## 1. 왜 고치는가

- `1.1.0`의 고급 FX 랙은 언제나 탭 채널 하나만 고친다. MASTER BUS는 선택되지 않고 FX 값도 없다. 그래서 게이트·컴프레서·패닝을 모든 탭에 거는 방법이 없다. 도움말 문구도 처음부터 "채널별 FX"였다.
- 노멀라이저는 `normMode = "follow" | "on" | "off"` 값 하나에 두 축이 섞여 있다. a축은 "전역을 따르는가"이고, b축은 "따르지 않을 때 켜는가 끄는가"이다. 화면에는 버튼 세 개짜리 한 그룹으로 나온다.
- 채널에서는 프리셋을 고를 수 없고 사용자 프리셋도 없다.
- "전역 따름" 상태에서 목표·속도·구간을 만지면 표시 없이 `"on"`으로 바뀐다(`fx-rack-view.ts`, `norm-visualizer.ts`).
- 기술 제약: 탭마다 소리가 그 탭 페이지 안에서 처리되므로 진짜 마스터 버스는 없다. "모든 채널"은 모든 채널이 물려받는(또는 더해 받는) 값으로만 만들 수 있다.

### 사용자가 정한 모양 방향 (2026-11-17)

> 계기: 질문 6(활성 채널 표시) 시안의 가·나·다 안을 모두 기각한 뒤 사용자가 아래 논리를 직접 제시했다. "나보다 네가 더 좋은 안을 낼 수 있으니"라며 사고의 흐름을 나눈 것이다.

**사용자의 논리 (원문 요지, 순서 그대로)**
1. 실물 오디오 믹서가 백라이트 버튼으로 뮤트·솔로·액티브를 표현하는 것은 하드웨어 제약 때문이다. 채널 전면 전체를 화면으로 만들기에는 단가가 맞지 않는다.
2. 전면을 화면으로 바꾸면 오른 단가를 설명해야 한다. 그런데도 페이더 같은 것이 하드웨어로 남은 이유는 납득시키기 어렵다. "바뀐 하드웨어에 맞는 조작성을 충분히 고민하지 않았다"는 비난을 피하기 어렵다.
3. 이 앱은 인디 앱이다. 무료 오픈소스 Chrome 확장으로, 개인이 AI 바이브코딩으로 시작했다. 그런 설명 책임을 지지 않고, 처음부터 전부 화면에 그려지며, 무료라는 가격이 모든 것을 상쇄한다.
4. 그러니 화면을 모험적으로 구성해도 된다.
5. 활성 채널은 테두리가 아니라 채널 자체에 하이라이트를 준다.
6. 음소거면 채널 바탕을 빨갛게 한다. 눈이 불편하지 않은 범위에서, 테마색이 허용하는 어울리는 조합으로 한다.
7. 솔로면 솔로 색, 포커스면 포커스 색을 준다.
8. 버튼 덱을 "오디오 믹서의 백라이트 버튼" 인상이 아니라 GUI 하단 덱처럼 만든다.
9. 클래식 룩은 활성 채널 하이라이트만 조금 개선해 클래식 테마로 계속 제공한다.
10. 테마 색만 바꾸던 패널에서 이 모양(클래식/모던)도 바꿀 수 있게 한다.
11. 판 순서는 이렇다.
    1. 1.2.0을 먼저 빌드해 버그를 본다.
    2. 버그는 1.2.1 식으로 올려 가며 고친다.
    3. 다 고친 뒤 2.0.0-preview로 "클래식과 모던을 유지보수 부담이 늘지 않는 방법으로 함께 제공하는 법"을 찾는다.
    4. 완성되면 2.0.0을 출시한다.

**에이전트가 덧붙인 것 (시안 `mockups/v9-7_channel_state_look.html`의 "모던 미리보기")**
- 그대로 옮기면 걸리는 점이 있다. 1.1.0은 이미 **바탕 밝기로 재생/대기를 표시**한다(`strip-view.ts`: 재생 = `raised`, 대기 = `surface` + 불투명도 0.74). 그래서 선택까지 바탕으로 칠하면 다시 겹친다.
- 그래서 원칙을 **시각 요소 하나에 뜻 하나**로 둔다.

  | 보이는 것 | 뜻 |
  |---|---|
  | 바탕 색조 | 소리 상태: 음소거 빨강 · 솔로 주황 · 포커스 Focus색 · 보통 중립. 테마 상태색을 surface에 17~19% 섞음 |
  | 밝기 + 떠오름 | 선택(고급 FX 랙의 대상) |
  | 불투명도 + 구역 | 대기. 재생/대기 구역이 이미 갈라져 있어 바탕 밝기를 재생 표시에서 떼어 냄 |
  | 글자 칩(음소거/솔로/포커스) | 색각 보조 |
  | 하단 툴바 밑줄 | 어느 버튼이 켜졌는지 |

- 우선순위는 음소거 > 솔로 > 포커스다. 음소거된 채널은 실제로 소리가 나지 않기 때문이다.
- 하단 덱은 재생·음소거·솔로·포커스·핀을 한 줄 툴바로 둔다. 켜진 것은 상태색 글자와 밑줄로만 보인다(시안 그대로).
- 유지보수 방향(제안, 미확정): 두 모양이 **같은 DOM**을 쓰고 루트의 `data-look="classic|modern"` 속성과 CSS 토큰만 바꾸게 한다. 그러면 기능 코드가 하나로 유지된다. 2.0.0-preview에서 검증할 것.

**판 번호 주의 (2.0.0-preview 전에 정할 것)**
- Chrome `version`에는 숫자만 쓸 수 있어 `-preview`는 `version_name`에만 붙는다.
- 이 프로젝트 규칙상 Chrome에 불러온 번호는 다시 쓸 수 없다. 그래서 미리보기를 `version: 2.0.0`으로 내면 정식판은 2.0.0이 될 수 없다. 예를 들어 미리보기를 `1.9.x`(`version_name: 2.0.0-preview.N`)로 매기는 식으로 피해야 한다.
- 또 유의적 버전 규칙상 2.0.0(메이저)은 공개 인터페이스(조작 의미·저장 설정 구조 등)가 호환되지 않게 바뀔 때 올린다. 클래식을 유지하는 선택형 모양 추가라면 엄밀히는 마이너다. 2.0.0으로 낼 근거를 그때 사용자와 확인한다.

**함께 정리할 것 (2.0.0 때)**: 도메인 핀(📌)이 Solo와 같은 주황(accent)을 쓴다.

**요약**: 순서는 1.2.0(FX 범위 개편 + 클래식 활성 표시 개선) → 1.2.x(버그) → 2.0.0-preview(클래식·모던 공존 방식) → 2.0.0이다.

### 결정에서 따라 나오는 모델

- 카드마다 축을 둘로 나눈다. **따를지**는 카드 아래 줄의 `🔗 모든 채널 따름` ↔ `● 이 채널만`이고, **어떻게 걸지**는 카드 위쪽의 ON/OFF·프리셋·값이다.
- `1.1.0` `normMode` 대응: `follow` → 모든 채널 따름, `on` → 이 채널만 + ON, `off` → 이 채널만 + OFF. 저장된 옛 설정은 이 표대로 자동 변환해 보존한다(마이너 버전 근거).
- 패닝만 "따름/따로" 대신 "더하기" 규칙을 쓴다.

## 4. 1.2.0 구현 계획과 진행 기록

가지: `work/fx-scope-ux` (`main`의 `b41b457`에서 땀). 승인 시안: `mockups/v9-8` + `v9-9`(색·빗금) + `v9-10`(Focus 색).

### 경계
- 콘텐츠 쪽(`dsp-chain.ts`, `audio-hook.ts`)이 받는 `DspConfigPayload` 모양은 바꾸지 않는다. 바꾸는 것은 그 앞단의 설정 구조(백그라운드)와 팝업이다.

### 데이터 구조 (`types.ts`)
- `NormParams { targetLufs, speed, rangeLowLufs, rangeHighLufs, zeroReturnRate }`
- `NormSlot = NormParams + { enabled, presetId, modified }`. `presetId`는 기본 4종 키, 내 프리셋 `u…`, 또는 `""`(사용자 지정)이다.
- `GateSlot { enabled, thresholdDb }`, `CompSlot { enabled, ratio }`, `FxLayer { norm, gate, comp }`
- `ChannelFxState { own: Partial<FxLayer>; pan }`. `own`에 모듈이 없으면 "모든 채널 따름"이다.
- `PersistedSettings`에서 `autoNormEnabled`·`autoNormPreset`을 빼고 `globalFx: FxLayer`, `globalPan`, `userPresets[]`를 더한다.
- `modified`는 비교로 계산하지 않고 저장한다. "고를 때 복사"이므로, 덮어쓴 뒤 다른 채널에 수정됨이 붙으면 안 된다.

### 옛 설정 변환
- 설정: `autoNormEnabled`/`autoNormPreset` → `globalFx.norm`.
- 세션(탭별 fx)
  - `normMode follow` → 따름
  - `on` → `own.norm{enabled:true, presetId:"", 옛 값}`
  - `off` → `own.norm{enabled:false, …}`
  - gate/comp는 켜져 있거나 기본값과 다를 때만 `own`으로 옮긴다.

### 메시지
- 기존 `UPDATE_TAB_FX`는 `EDIT_FX { target: "global" | tabId, edit }` 하나로 바꾼다. `edit`은 detach / relink / set(module, patch) / pan / pickPreset이다.
- 새로 더할 메시지: `SAVE_USER_PRESET`, `OVERWRITE_USER_PRESET`, `RENAME_USER_PRESET`, `DELETE_USER_PRESET`.
- 의미가 바뀌는 메시지
  - `TOGGLE_AUTO_NORM` → `globalFx.norm.enabled`
  - `SET_AUTO_NORM_PRESET` → 프리셋 id를 받아 전역에 적용

### 팝업
- `fx-rack-view.ts`: 범위 탭 + 요약 카드 4개 + 따름 줄로 다시 쓴다.
- 새 모듈 `fx-detail-view.ts`: 세부 창을 맡는다. 노멀라이저 세부는 기존 `norm-visualizer` 시각화를 재사용한다.
- `master-view.ts`: 선택 가능하게 하고 `전체 FX` 버튼을 더한다. 선택되면 떠오른다.
- `strip-view.ts`
  - 선택 = 떠오름(1px 청록 테두리 제거)
  - Focus 색 토큰 사용
  - 음소거 빗금, 빗금 색 = 원인
  - grip 줄의 `N` 배지를 `N G C P` 칩으로 바꿈
- `norm-popover.ts`: 내 프리셋도 목록에 넣는다.

### 구현 중 정한 것 (시안과 다른 점)
- `N G C P` 칩은 페이더 아래가 아니라 grip 줄에 둔다(높이를 늘리지 않으려고).
- 범위 탭은 "이 채널"만 쓰고 사이트 이름은 머리 줄·툴팁에 둔다(탭 폭에서 잘림).
- 팝업 높이가 실제로 약 445px이라 세부 창은 약 370px이고 넘치면 창 안에서 스크롤한다.
- 세부 창은 승인 설계대로 채널 줄과 마스터를 가린다. 그래서 "모든 채널"일 때 떠오른 마스터가 창 아래에 가려지고, 범위는 랙의 탭이 알려 준다.
- 스트립·마스터의 조작부(버튼·페이더·수치창·grip)를 누르면 선택만 옮기고 범위는 유지한다. 빈 곳을 눌러야 범위가 바뀐다.
- 음소거는 재생 여부와 관계없이 빨간 빗금을 그린다.
- `Focus α` 상자도 Focus 색으로 칠한다. `version_name`은 지우고 `version: 1.2.0`만 둔다.
