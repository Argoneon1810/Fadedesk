## 1. 어디에서, 어떤 식으로 보이는가? (Surface & Console Layout)

### 1.1 진입 위치와 툴바 아이콘 피드백
- **호출 위치**: Chrome 우측 상단 확장프로그램 툴바 아이콘 클릭 **또는** 전역 단축키(기본 예: `Alt+Shift+M`, 브라우저 단축키 설정에서 변경 가능)로 현재 화면·전체화면을 벗어나지 않고 즉시 열리는 **컴팩트 툴바 팝업 콘솔**.
- **아이콘 배지**: 팝업을 열기 전에도 현재 소리 나는 탭 수(예: `3`)와 특수 상태(`S` Solo 활성 / `F` Focus 활성 시 배지 색상 구분)를 툴바 아이콘에 작게 표시.

### 1.2 전체 레이아웃 골격: "리스트 카드가 아닌 슬림 세로 채널 스트립"
기존 미디어 확장들(`GMC-Enhance`, Chrome 미디어 허브 등)처럼 넓은 가로 카드를 세로로 쌓는 비대한(bulky) 구조를 버리고, **슬림한 세로 오디오 채널 스트립(Channel Strip)들이 가로로 나란히 서는 콘솔 구조**를 채택한다.

```text
+-----------------------------------------------------------------------+
| [상단 미니 바] 활성 3 · 대기 1        Focus 감쇠: [-12 dB]   [S/F 해제] |
+---------------+---------------+---------------+-------+---------------+
|  [치지직 아이콘] |  [유튜브 아이콘] |  [유튜브 아이콘] | (구분) |    MASTER     |
|  침착맨 라이브.. |  Lo-Fi BGM..  |  강의 녹화본..  |       |   전체 출력    |
|  (클릭→탭이동)  |  (클릭→탭이동)  |  (일시정지됨)   |       |               |
|               |               |               |       |               |
|    +12 dB     |    +12 dB     |    +12 dB     |       |    +12 dB     |
|      |  █     |      |        |      |        |       |      |  █     |
|    0 dB ═══   |    0 dB ───   |    0 dB ───   |       |    0 dB ═══   |
|      |  █     |      |  ▒     |      |        |       |      |  █     |
|      |  █     |    ══╪══ (고스트)|   ══╪══     |       |      |  █     |
|      |  █     |      |  █     |      |        |       |      |  █     |
|    -60 / -∞   |    -60 / -∞   |    -60 / -∞   |       |    -60 / -∞   |
|               |               |               |       |               |
|    0.0 dB     |   -6.0 dB     |   -3.0 dB     |       |    0.0 dB     |
|  (실효 0.0)   |  (실효 -18.0)  |    (대기중)    |       |               |
|               |               |               |       |               |
|  [⏸]   [📌]   |  [⏸]   [📌]   |  [▶]   [📌]   |       |   [⏸ 전체정지] |
| [M] [S] [F*]  | [M] [S] [F ]  | [M] [S] [F ]  |       |   [M 전체무음] |
+---------------+---------------+---------------+-------+---------------+
```

- **부피 최소화 치수 감각**:
  - 채널 스트립 1개 폭을 약 `72~80px`로 슬림하게 설계한다.
  - 탭이 2개면 팝업 폭도 좁고 단단하게(`~260px`) 열리고, Chrome 팝업 최대 폭(`800px`) 안에서 **스크롤 없이 최대 7~8개 채널 + 우측 고정 Master 스트립**이 한눈에 들어온다(초과 시에만 채널 구역 가로 스크롤).
- **채널 정렬 순서**:
  1. 좌측: **현재 소리 출력 중(Playing)** 인 탭들
  2. 우측(구분선 앞): **일시정지(Paused)** 상태인 미디어 탭들 (살짝 톤을 낮춰 구분하되 사라지지 않아 언제든 `▶`로 재개 가능)
  3. 우측 끝 고정: **Master 스트립**

## 2. 단일 채널 스트립의 구성 요소 (위 → 아래)

탐색바·썸네일·배속 등 부피만 키우는 요소를 모두 덜어내고 3단으로 압축한다.

1. **상단 — 탭 식별 & 점프 헤더**
   - 사이트 파비콘 + 짧은 탭/미디어 제목(마우스 호버 시 전체 제목·도메인 툴팁 표시).
   - **원클릭 탭 이동**: 헤더 클릭 시 해당 탭이 있는 Chrome 창을 앞으로 가져오며 그 탭으로 즉시 포커스 전환.
2. **중단 — 세로 dB 로그 페이더 + 실시간 레벨 미터(VU)**
   - **범위**: 하단 끝 `-∞`(`-60 dB` 이하 무음 스냅) ~ 기준선 `0 dB`(상단 70% 지점 눈금) ~ 상단 끝 `+12 dB`(약 4배 증폭).
   - **일체형 레벨 미터**: 페이더 바로 옆 얇은 막대로 실시간 출력 레벨을 표시해, 여러 탭 중 지금 소리가 나는 탭을 눈으로 즉시 찾는다.
   - **보안 제한(DRM·외부 직결) 예외 표시**: 증폭이 막힌 영상은 `0 dB` 위쪽 구간만 잠금 톤으로 막히고 `0dB MAX` 캡 아이콘이 작게 표시된다(볼륨 줄이기·음소거·재생 제어는 동일하게 작동).
   - **수치 라벨**: 페이더 하단에 `-6.0 dB` 형태로 표시(더블클릭 `0.0 dB` 원복, 클릭 시 직접 숫자 입력 가능).
3. **하단 — 초소형 액션 클러스터**
   - 1열: **`▶/⏸`** (재생/일시정지) + **`📌`** (현재 탭 dB를 해당 도메인 기본값으로 저장/고정 토글)
   - 2열: **`M`** (Mute) · **`S`** (Solo) · **`F`** (**Focus**)

## 3. 핵심 차별 기능: `Focus 모드 (F)` = 일반화된 Solo (Smoothed One-Hot Weight)

### 3.1 통합 가중치 모델 (승인 확정안)
`Solo`와 `Focus`를 별개 로직으로 쪼개지 않고 **단일 스무딩 파라미터 $\alpha \in [0, 1]$를 갖는 일반화된 원-핫(One-Hot) 가중치 곱셈 모델**로 통합한다.

채널 $i$의 사용자 설정 페이더 선형 게인을 $g_i = 10^{G_i / 20}$, 마스터 게인을 $g_{\text{master}}$라 할 때 각 채널의 최종 실효 출력은 다음과 같다.

$$g_i^{\text{eff}} = g_{\text{master}} \times g_i \times w_i(\alpha) \times (1 - \text{muted}_i)$$

- **평상시 (Normal, $\alpha = 1$)**: 모든 채널 가중치 $w = [1, 1, \dots, 1]$ (`0 dB` 감쇠 없음)
- **Solo 모드 (`S`, $\alpha = 0$ — 순수 원-핫)**: 선택 채널 $w_k = 1$, 비선택 채널 $w_{j \neq k} = 0$ (`-∞ dB` 완전 무음)
- **Focus 모드 (`F`, $0 < \alpha < 1$ — 스무딩된 원-핫)**:
  - 선택 채널 $w_k = 1$ (원래 설정 볼륨 그대로 유지하여 클리핑 방지)
  - 비선택 채널 $w_{j \neq k}(\alpha) = 10^{-D_{\max}(1 - \alpha)/20}$ (청감 로그 스케일에 맞춘 스무딩 가중치; 예: $D_{\max} = 40\text{ dB}$ 기준 $\alpha = 0.70 \Rightarrow -12\text{ dB} \approx 0.25\times$, $\alpha = 0.50 \Rightarrow -20\text{ dB} = 0.10\times$, $\alpha \to 0$이면 자연스럽게 Solo로 수렴)
- **스무딩 레벨 제어**: 상단 미니 바에 **Focus 스무딩 슬라이더/노브**를 두어, 스무딩 값을 올리고 내리는 것만으로 "거의 Solo에 가까운 강한 집중"부터 "배경음을 살짝만 낮춘 완만한 공존"까지 연속적으로 조절한다. 전환 시에는 약 `80~100ms` 램핑을 적용해 틱 노이즈를 막는다.

### 3.2 페이더 설정값 보존 (비파괴 오버레이)
- Focus나 Solo를 켜더라도 **다른 채널들의 원래 페이더 손잡이 위치($G_i$)는 덮어쓰지 않고 그대로 보존**한다.
- 대신 비-Focus 채널 트랙 위에 가중치 $w_j(\alpha)$가 곱해진 실효 출력 레벨을 **반투명 고스트 표시**로 함께 보여 주며, 해제 시 즉시 원래 밸런스로 복귀한다.

### 3.3 `M` · `S` · `F` 간 우선순위와 전환 규칙 (확정)
1. **`M`(개별 음소거) 최우선 보존**: 이미 `M`으로 꺼 둔 탭은 다른 탭에 `F`가 켜져도 계속 무음(`0`)을 유지한다.
2. **`F`(Focus) 원클릭 주인공 교체**: A 채널이 `F`인 상태에서 B 채널의 `F`를 클릭하면 **즉시 Focus가 A → B로 교체**된다(`Shift+클릭` 시 복수 채널 동시 Focus 허용, 켜진 `F` 재클릭 시 해제).
3. **`S`(Solo)와 `F`(Focus)의 관계**: `S`는 $\alpha = 0$ 극단값을 즉시 적용하는 하드 격리 토글로 동작하며, 해제 시 직전 상태로 복귀한다.

## 4. 고려한 5가지 핵심 유저 인터랙션 경로

### 경로 1: 현재 작업을 멈추지 않고 백그라운드 볼륨 즉시 조절
1. 코딩/문서 탭 작업 중 다른 창·백그라운드 탭 소리가 거슬림 → 단축키(`Alt+Shift+M`) 또는 아이콘 클릭으로 팝업 오픈.
2. 레벨 미터(VU)가 움직이는 채널을 즉시 확인 → 해당 스트립 위에서 **마우스 휠 스크롤**(기본 `1.5 dB` 단위, `Shift+휠` `0.5 dB` 미세 단위) 또는 페이더 드래그로 볼륨 조절.
3. `0 dB` 기준점으로 즉시 되돌릴 때는 페이더 **더블클릭**.
4. `Esc` 키 또는 바깥 클릭으로 팝업을 닫고 원래 작업 계속(탭 전환 0회).

### 경로 2: 멀티 방송/영상 동시 시청 중 `Focus` 스위칭
1. 스포츠/인방 중계 탭 2개 + 음악 탭 1개를 동시에 틀어 둠.
2. 주력 탭 A의 **`F`** 클릭 → 나머지 두 탭이 `-12 dB` 아래로 내려가 내용이 안 섞이고 A의 멘트가 선명하게 들림(나머지 탭에서도 함성·상황 변화는 작게 들림).
3. 서브 탭 B에서 중요한 장면이 들림 → 팝업을 열고 탭 B의 **`F`** 한 번 클릭 → 즉시 주인공이 B로 교체됨.

### 경로 3: 일시정지된 미디어 재개 & 해당 탭으로 점프
1. 아까 멈춰 둔 음악 탭을 다시 틀고 싶음 → 팝업의 일시정지 구역 스트립에서 **`▶`** 클릭 → 탭을 찾아 헤맬 필요 없이 백그라운드에서 즉시 재생 시작.
2. 영상 화면을 직접 봐야 할 때만 스트립 **상단 파비콘/제목 영역 클릭** → 해당 창과 탭으로 즉시 이동.

### 경로 4: 도메인 기본 볼륨 기억과 멀티탭 독립 조작 분리
1. 평소 소리가 너무 큰 사이트에서 페이더를 `-10 dB`로 내린 뒤 **`📌`(핀)** 클릭 → 도메인 기본값으로 저장됨.
2. 이후 그 사이트의 새 탭을 열면 `-10 dB`로 자동 시작함.
3. 같은 사이트 탭을 2개 열어 두고 한쪽 페이더만 `+6 dB`로 올려도 **다른 탭의 `-10 dB`와 도메인 기본값(`-10 dB`)은 건드리지 않고 해당 탭만 독립 변경**됨(핀을 다시 눌러 갱신할 때만 기본값 변경).

### 경로 5: 키보드만으로 조작 (마우스리스 워크플로)
1. 단축키로 팝업 호출 → `←` / `→` 방향키로 채널 스트립 간 포커스 이동.
2. `↑` / `↓` 방향키로 선택 채널 dB 조절(`0` 키: `0 dB` 리셋).
3. `Space`: 재생/일시정지, `M`: 음소거, `S`: Solo, `F`: Focus, `Enter`: 해당 탭으로 점프, `Esc`: 팝업 닫기.
