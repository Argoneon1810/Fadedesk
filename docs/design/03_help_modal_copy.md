# `0.4.0` 박스 배지 타이틀 · `?` 튜토리얼 모달 · 중첩 시각 용어 카드 명세

## 1. 상단 브랜드 타이틀 & `?` 트리거
- **박스 배지 타이틀 (`SOUND MANAGER`)**: 굵은 대문자(`font-weight: 800`, `letter-spacing: 0.08em`) + 각진 콘솔 명판 테두리(`border: 1.5px solid var(--c-primary)`, 음각 배경 패딩 `2px 7px`, 좌측 브랜드 도트 결합)
- **도움말 버튼 (`?`)**: 타이틀 바로 우측 `20×20px` 원형 아이콘 버튼 (`aria-haspopup="dialog"`, 클릭 시 모달 오픈)

## 2. 용어 원칙: 추상 음향 개념어 배제 vs 실물 조작부 명칭(Tangible Terms) 채택

- **Easy 모드에서 걷어내는 말 (개념·원리 전문어)**: `LUFS`, `Pre-Fader`, `다이내믹 레인지`, `히스테리시스`, `메이크업 게인`, `원-핫`, `CORS`
- **Easy 모드에서 그대로 쓰고 시각 카드로 연결하는 말 (눈에 보이는 실물 부품명 8종)**:
  문장 안에 밑줄·배지 형태의 인터랙티브 칩(`.term-chip`)으로 표기한다.
  1. **`페이더`**: 채널 중앙의 세로 볼륨 레일과 눈금 슬롯 전체
  2. **`노브`**: 페이더 및 상단 `Focus` 슬라이더 위에서 마우스로 잡고 움직이는 사각 캡
  3. **`레벨 미터`**: 실제 출력 음량에 맞춰 실시간으로 점등되는 우측 20단 컬러 막대
  4. **`수치 표시창`**: 페이더 아래 현재 볼륨 숫자를 보여주고 클릭 시 직접 입력하는 창
  5. **`드래그 핸들`**: 채널 맨 위 점 6개(`⠿`) 모양의 순서·구역 이동 손잡이
  6. **`스위치 뱅크`**: 채널 맨 아래 `M`(음소거) · `S`(단독) · `F`(집중) 3버튼 묶음
  7. **`도메인 핀`**: 재생 버튼 옆 압정 모양의 사이트 기본 볼륨 고정 스위치
  8. **`마스터 버스`**: 콘솔 오른쪽에 고정된 `전체 출력` 전용 스트립

## 3. 중첩 시각 용어 카드 (Nested Visual Callout Modal) 동작 규격

| 조작 | 동작 상태 | 닫히는 조건 |
| :--- | :--- | :--- |
| **마우스 호버 (`pointerenter`)** | **임시 미리보기 (`hover` 상태)** — 모달 내부 오버레이 레이어에 미니 스트립 일러스트(해당 부품만 테마 강조색 하이라이트 + 화살표 콜아웃)와 1~2줄 설명 표시 | 커서가 칩 밖으로 나가면(`pointerleave`) 즉시 닫힘 (단, 이미 클릭 고정된 상태면 유지) |
| **클릭 / `Enter` (`click`)** | **고정 보기 (`pinned` 상태)** — 칩 테두리가 강조되며 커서를 치워도 중첩 카드가 열린 채로 유지됨 | ① 해당 칩이 포커스를 잃을 때(`blur`), ② 중첩 카드 바깥 클릭 시, ③ `Esc` 키 입력 시 (중첩 카드만 먼저 닫히고 메인 모달은 유지) |

## 4. `[기본 사용법 (Easy)]` 4단계 문구 (실물 부품 칩 `[용어]` 표기)

1. **탭별 볼륨 조절과 직접 입력**
   - 모든 창의 재생 탭을 한곳에서 개별 제어합니다.
   - 채널 중앙 **[페이더]**의 사각 **[노브]**를 잡고 위아래로 드래그하거나 마우스 휠을 굴려 볼륨을 조절합니다(`0` 눈금 위로 올리면 원본 최대치 이상으로 증폭되며 우측 **[레벨 미터]**로 현재 출력 크기를 확인).
   - 아래 **[수치 표시창]**을 클릭하면 숫자를 직접 입력할 수 있고, **[노브]**를 더블클릭하면 기본값(`0.0`)으로 복귀합니다.

2. **자동 볼륨 균일화 (`균일 N`)**
   - 영상·음원마다 제각각인 볼륨 편차를 자동으로 맞춥니다.
   - 상단 **`균일 N`**을 켜 두면 탭마다 기준 볼륨이 다르거나 다음 곡·쇼츠로 넘어갈 때, 지나치게 큰 소리는 낮추고 작은 소리는 끌어올려 **[노브]**를 매번 다시 만지지 않아도 일정한 청취 볼륨을 유지합니다.

3. **집중 청취와 전체 제어 (`M · S · F` & 마스터)**
   - 주목할 탭만 또렷하게 남기고 배경 탭 볼륨을 정리합니다.
   - 하단 **[스위치 뱅크]**에서 **`F`**를 누르면 선택 탭은 유지하고 나머지 탭만 일정 비율로 낮추며, **`S`**는 단독 청취, **`M`**은 개별 음소거로 동작합니다.
   - 콘솔 우측 **[마스터 버스]**에서는 모든 탭의 전체 출력 볼륨과 일괄 정지·음소거를 한 번에 제어합니다.

4. **채널 정렬 · 빠른 일시정지 · 기본값 고정**
   - 자주 쓰는 배치와 사이트별 시작 볼륨을 유지합니다.
   - 상단 **[드래그 핸들]**을 좌우로 끌어 채널 순서를 바꾸며, 중앙 구분선 너머 우측(대기 구역)에 놓으면 즉시 일시정지되고 좌측으로 옮기면 즉시 재생됩니다.
   - **[도메인 핀]**을 켜 두면 이후 같은 사이트를 새 탭으로 열 때 현재 볼륨이 초기값으로 자동 적용됩니다.
