## 1. 기술적 지원 범위 및 브라우저 보안 경계 (`tabCapture` 미사용 기준)

- **지원 대상 (유튜브, 치지직, 트위치, 사운드클라우드 등 동일 출처 및 MSE `blob:` / WebAudio 사이트)**:
  - 페이지 `MAIN` 월드에서 순수 네이티브 WebAudio 노드(`BiquadFilterNode`, `DynamicsCompressorNode`, `StereoPannerNode`, `AnalyserNode`, `GainNode`)만으로 신호 체인을 구성한다.
  - 외부 스크립트나 `AudioWorklet` `blob:` URL을 쓰지 않으므로 사이트별 CSP·Trusted Types 제약과 충돌하지 않으며 오디오 지연(Latency)이 추가되지 않는다.
- **보안 제한 대상 (교차 출처 `crossorigin` 미지정 · 넷플릭스 등 EME DRM · WebRTC `srcObject`)**:
  - `chrome.tabCapture` 없이는 브라우저 보안 정책상 원본 파형(PCM) 접근과 WebAudio 노드 연결이 차단된다.
  - 기존 `+12 dB` 증폭 제한(`보안 0dB 상한`)과 동일하게 고급 DSP·노멀라이징은 비활성(바이패스) 상태로 표시하되, 기본 볼륨 감쇠(`-60 ~ 0 dB`)·음소거·재생 제어·Focus 감쇠·드래그 정렬은 그대로 동작한다.

## 2. 실시간 스트리밍 노멀라이징 방법론 목록 (참고 카탈로그)

전체 파일을 미리 스캔(2-Pass)할 수 없는 실시간 탭 오디오에서 구현 가능한 4가지 기술 방법론을 기록해 둔다.

| 구분 | 방법론 명칭 | 신호 처리 원리 | 적합한 청취 상황 | 한계 및 주의점 |
| :--- | :--- | :--- | :--- | :--- |
| **방법 A** | **완만한 목표 음량 맞춤**<br>*(Smart Loudness Leveler / AGC)* | 청감 가중 필터(K-weighting 근사)를 거친 단기 RMS 에너지를 측정해 목표 음량과의 차이만큼 게인을 서서히 추종하며, **무음 구간 게인 동결(Gate Freeze)** 과 상한 리미터를 결합 | 탭마다 평균 녹음·마스터링 볼륨이 제각각일 때(작은 강의/방송 vs 큰 음악/광고) 비슷한 크기로 맞출 때 | 무음 동결이 빠지면 침묵 구간에 배경 잡음(화이트노이즈)이 끌어올려지므로 반드시 결합 필요 |
| **방법 B** | **피크 상한 리미터**<br>*(Ceiling Peak Limiter)* | 평소 작은 소리는 건드리지 않고, 지정한 상한(예: `-2 dBFS`)을 넘는 순간적인 폭음·비명만 빠른 Attack으로 억제 | 원래 다이내믹과 볼륨 밸런스는 유지하면서 갑작스러운 귀 아픈 큰 소리만 막고 싶을 때 | 작게 녹음된 소리를 키워 주지는 않음 |
| **방법 C** | **다이내믹 레인지 평탄화**<br>*(Broadcast / Night Leveler)* | 한 채널 안에서 작은 속삭임은 끌어올리고(Upward) 큰 효과음은 눌러서(Downward) 음량 편차 폭 자체를 좁힘 | 한 방송·영화 안에서 말소리는 너무 작고 효과음·후렴구는 너무 커서 볼륨을 계속 손으로 오르내려야 할 때 | 음악 감상 탭에 강하게 걸면 강약 대비가 줄어 평면적으로 들릴 수 있음 |
| **방법 D** | **원샷 스냅샷 맞춤**<br>*(One-Shot Auto-Trim)* | 실행 시점부터 짧은 구간(예: 2~3초)의 평균 음량을 재서 채널 페이더 dB만 목표치로 **한 번** 옮기고 이후에는 게인을 고정 | 재생 도중 실시간으로 볼륨이 변하는 느낌(펌핑) 없이 초기 밸런스만 빠르게 맞추고 싶을 때 | 같은 탭에서 음량이 다른 다음 영상으로 넘어가면 다시 실행해야 함 |

> **핵심 모델링 확정 — 계층적 오디오 구조와 Pre-Fader 채널 다이나믹 노멀라이징**:  
> 우리 앱은 각 **탭을 하나의 믹서 채널**로 다루지만, 각 탭 안에서는 멜론의 서로 다른 장르/음압 음원이나 유튜브의 '고자극 레드존 마스터링 영상'과 '정석 `-16 LUFS` 영상'처럼 **서로 다른 엔지니어링 기준을 가진 하위 음원들이 시간순으로 바뀌며 단일 탭 출력으로 흘러나오는 계층 구조**를 갖는다.  
> 따라서 최우선 과제는 마스터단 노멀라이징이나 정적 스냅샷이 아니라, **사용자 채널 페이더 앞단(Pre-Fader)에서 각 탭 입력을 일정한 기준 음압으로 정규화하는 '채널별 다이나믹 노멀라이저'** 다.

## 2-1. 본 앱이 채택하는 '채널별 다이나믹 노멀라이저' 설계 (Pre-Fader Input Conditioner)

사용자가 채널 페이더로 정한 탭 간 볼륨 비율(예: 브금 탭 `-9 dB`, 메인 방송 탭 `0 dB`)이 **곡이나 영상이 바뀌어도 흔들리지 않도록**, 페이더 앞단(`Pre-Fader`)에서 아래 세 가지 요구사항을 단일 파이프라인으로 동시에 충족한다.

1. **귀를 찌르지 않음 (Fast Ceiling Guard + K-Weighting 청감 측쇄)**:
   - 측쇄(Sidechain) 측정 경로에 고역대(`1.5~4 kHz`) 민감도를 반영한 **K-가중 필터(High-Pass + High-Shelf)** 를 두어, 귀를 찌르는 고자극 마스터링 음원을 실제 청감 피로도에 맞게 더 크게 판정한다(원음 경로에는 EQ 왜곡을 입히지 않음).
   - 급격한 레드존 피크(`0 dBFS` 근접)가 들어오는 첫 수 ms 동안 **고속 상한 리미터(Fast Attack Ceiling)** 가 먼저 귀를 보호한다.
2. **평균 음압을 일정하게 유지 (Slow RMS Leveler + 무음 동결)**:
   - 한 음원이 재생되는 동안에는 `2~4초` 단위의 완만한 창(Slow Window)으로 목표 기준 음압(예: `-16 LUFS` 상당)을 추종하여, 음악·음성의 자연스러운 단기 강약(그루브·어택)을 뭉개지 않는다.
   - 침묵·페이드아웃 구간(예: `-45 dBFS` 이하)에서는 현재 게인을 동결(**Silence Freeze**)해 배경 화이트노이즈가 끌어올려지는 현상을 막고 최대 증폭 한계(예: `+10 ~ +12 dB`)를 둔다.
3. **음원이 바뀌어도 즉각 반응 (Track-Transition Fast Re-Lock)**:
   - 미디어 요소의 소스/메타데이터 전환 이벤트(`loadedmetadata`, `durationchange`, `emptied`) **및** 단기 에너지(`300~400ms`)와 장기 에너지(`3s`) 사이의 급격한 단차(예: 조용한 곡 직후 레드존 광고/EDM 진입)를 감지한다.
   - 음원이 갑자기 커진 전환 순간에는 빠른 감쇠 시정수(`~50ms`)로 즉시 게인을 낮춰 폭음을 막고, 갑자기 작아진 새 음원으로 바뀐 경우에도 평상시보다 빠른 복귀 시정수(`~0.6~1.0s`)로 새 음원의 평균 음압에 재동기화한다.

### `Easy Mode` vs `Advanced Mode` 역할 분담 (안)
- **`Easy Mode`**: 전문 용어나 방식 선택을 요구하지 않고, 위 3요소가 결합된 **채널별 Pre-Fader 다이나믹 노멀라이저 스위치(기본 표준 프리셋)** 만 간결하게 제공한다.
- **`Advanced Mode`**: 선택된 채널에 대해 노멀라이저 세부 성향(목표 음압·반응 속도·최대 증폭 폭 및 실시간 보정 dB 게이지)과 함께 **스테레오 패닝(`Pan`)**, **노이즈 게이트(`Gate`)**, **컴프레서(`Compressor`)** 를 열어 조절할 수 있게 한다.

## 3. 고급 DSP 체인 및 화면 노출 원칙 (`Easy` vs `Advanced`)

1. **채널 내부 신호 처리 순서 (Pre-Fader 정규화 반영안)**:
   ```text
   탭 내 하위 음원들 ──► [1. Gate (무음·바닥 잡음 차단, 선택)]
                     ──► [2. Pre-Fader Channel Dynamic Normalizer (음원 간 기준 음압 정규화)]
                     ──► [3. Compressor (채널 다이내믹 압축, 선택)]
                     ──► [4. Channel Fader (-60~+12 dB) × Focus/Solo 가중치 (사용자 믹싱 의도)]
                     ──► [5. Stereo Pan (L ◄─ C ─► R)]
                     ──► [6. Safety Limiter]
                     ──► [AnalyserNode (최종 출력 VU 미터)] ──► 출력
   ```
2. **화면 밀도 보존 및 시안 기반 배치 결정**:
   - 현재 콘솔이 `Easy Mode`로서 이미 적정 밀도에 도달해 있으므로 기존 스트립 조작계를 해치지 않는다.
   - `Advanced Mode`의 세부 파라미터(`Gate`, `Compressor`, `Normalizer` 세부 조절)는 모든 스트립에 빽빽이 욱여넣지 않고 **선택된 채널에 대한 슬림 인스펙터(서랍/패널)** 구조를 우선 검토한다.
   - 단, **`Easy / Advanced` 전환 스위치와 노멀라이징 조작부의 구체적 배치 위치(상단 바 vs 하단/측면 도크 등)는 텍스트로 단정하지 않고 복수 배치 시안(`v6`)을 만들어 시각적으로 비교 후 확정**한다.

## 4. 채널 스트립 드래그 순서 변경 및 구역 간 상태 전환 (확정 요구사항)

각 채널 스트립에 전용 드래그 핸들을 두어 다음 두 가지 조작을 동시에 지원한다.

1. **그룹 내 순서 재배치**:
   - 좌측 **`재생 중`** 그룹 내부에서 스트립을 좌우로 드래그해 원하는 순서로 배치할 수 있다.
   - 우측 **`일시정지`** 그룹 내부에서도 동일하게 스트립 순서를 자유롭게 바꿀 수 있다.
2. **그룹 간 드래그 앤 드롭을 통한 즉각 재생/일시정지 전환**:
   - **`재생 중` → `일시정지` 그룹으로 드래그하여 놓기**: 놓는 즉시 해당 탭 미디어를 **일시정지**시키면서 `일시정지` 그룹의 드롭한 위치에 바로 끼워 넣는다.
   - **`일시정지` → `재생 중` 그룹으로 드래그하여 놓기**: 놓는 즉시 해당 탭 미디어를 **재생 재개**시키면서 `재생 중` 그룹의 드롭한 위치에 바로 끼워 넣는다(일시정지 탭이 0개일 때도 구분선/드롭 존을 드래그 중 노출해 언제든 던져 넣어 멈출 수 있게 한다).
