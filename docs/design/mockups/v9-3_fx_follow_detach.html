"모든 채널 따름"인 채널에서 값을 만지면 어떻게 반응해야 할까요?
이 시안에서는 1.1.0의 전역 따름 / 개별 ON / 개별 OFF 한 줄을 두 축으로 나눴습니다. 카드 아래쪽 줄은 따를지("모든 채널 따름" ↔ "이 채널만")이고, 카드 위쪽 ON/OFF와 값은 어떻게 걸지입니다. 그래서 1.1.0의 "개별 OFF"는 이제 "이 채널만 + OFF"입니다. 남은 질문은, 따르는 중인 채널에서 ON/OFF나 값을 만지는 순간 무엇이 일어나야 하느냐입니다. (1.1.0에서는 아무 표시 없이 "개별 ON"으로 바뀌었습니다.)
